# 橘橘桌宠 · 使用说明

一只会卖萌、能陪你聊天、还能自动回复微信/QQ 消息的桌面小橘猫。

## 功能一览

- 桌面悬浮透明桌宠，始终置顶，可随意拖动，不挡操作
- 五种状态：待机、眨眼、说话、开心、睡觉（长时间不理它会打盹）
- 单击逗它、双击直接和它聊天、右键弹出功能菜单
- 自动监听 PC 微信 / QQ 的新消息，按设定自动回复
- 三种回复模式：本地规则、AI 大模型、规则+AI 混合
- 图形化设置面板，所有话术、规则都能自己改，无需改代码
- 最小化到系统托盘，后台安静运行

## 快速开始

### 方式一：直接用 exe（推荐）

1. 打开 `dist\橘橘桌宠` 文件夹
2. 双击 `橘橘桌宠.exe`，首次使用会弹出使用须知，确认后小猫出现在屏幕右下角
3. 不想用了，右键小猫 → 退出（直接关文件夹不会让它退出，它会缩在右下角托盘里）

### 方式二：源码运行

需要 Python 3.10 及以上，安装依赖后运行：

```
pip install PySide6 uiautomation requests
python main.py
```

修改代码后想重新打包，双击 `build.bat` 即可。

## 怎么和它互动

- **单击**：逗它，会开心地蹦一下并随机说话
- **双击**：打开聊天窗口，直接打字和它对话
- **拖动**：按住左键把它放到屏幕任意位置
- **右键**：菜单里可以开关微信/QQ 自动回复、打开设置、隐藏或退出
- **托盘**：右下角小猫图标，左键点一下显示/隐藏，右键是完整菜单

## 开启微信 / QQ 自动回复

1. 先在电脑上打开并登录微信（或 QQ），双击好友进入一个聊天会话，保持软件在运行
2. 右键橘猫 → 勾选“微信自动回复”/“QQ自动回复”
3. 在设置 → 聊天平台里点“检测窗口”，显示“已找到窗口”就说明连接正常
4. 好友发来消息时，小猫会先提示收到消息，然后自动把回复发出去

建议设置：

- 消息检查间隔默认 2.5 秒，不建议调得太小
- 回复冷却默认 3 秒，防止连续消息时回复过于频繁
- 自动回复期间不要抢占鼠标键盘，否则可能打断输入

## 回复模式与 AI 配置

在设置 → 回复与 AI 里切换模式：

- **仅本地规则**：完全离线、免费、隐私安全，按关键词回复，没命中就用默认话术
- **仅 AI 大模型**：每条消息都交给 AI，像真人一样自然，需要 API Key
- **混合模式**：命中关键词走本地规则，没命中再问 AI，最省额度

本软件使用 OpenAI 兼容接口，主流平台的填法：

| 平台 | 接口地址 | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | 接入点 ID（ep- 开头） |
| 其他兼容服务 | 按服务商文档填写 | 按服务商文档填写 |

填好后在下方输入测试消息点“测试回复”，确认能正常回复再开启自动回复。

## 自定义关键词规则

设置 → 关键词规则：

- 第一列填关键词，多个用英文逗号隔开，消息里包含任意一个就算命中
- 第二列填回复内容，多条用英文竖线 `|` 隔开，命中后随机选一条
- “默认回复”是没命中任何规则时用的话术，每行一条
- “闲聊语”是单击宠物时它随机说的话，每行一条

## 风险提示与常见问题

1. 本软件通过 Windows 辅助功能模拟人工操作，**仅可用于个人便捷自动应答**，严禁用于骚扰、群发、营销引流
2. 微信、QQ 官方可能限制自动化操作，存在风控风险，建议先用小号测试，风险自行承担
3. 检测不到窗口：确认软件已登录、窗口没有被最小化到任务栏，并已打开一个聊天会话；微信/QQ 大版本更新后控件结构可能变化，需要更新适配
4. 回复发不出去：检查聊天软件的发送快捷键是否为默认的回车发送
5. 换电脑运行：把整个 `橘橘桌宠` 文件夹拷走即可，`config.json` 里保存了你的全部设置

## 目录结构

```
desktop_pet/
├── main.py                # 程序入口
├── build.bat              # 一键打包脚本
├── config.json            # 你的全部配置（运行后自动生成）
├── assets/                # 橘猫五状态图片
├── app/
│   ├── config.py          # 配置读写
│   ├── pet_window.py      # 桌宠窗口、动画、托盘、菜单
│   ├── chat_window.py     # 和宠物聊天窗口
│   ├── settings_dialog.py # 设置面板
│   ├── reply_engine.py    # 规则与 AI 回复引擎
│   ├── monitor.py         # 消息监听线程
│   └── worker.py          # 异步任务
└── platforms/             # 微信、QQ 平台适配
```
